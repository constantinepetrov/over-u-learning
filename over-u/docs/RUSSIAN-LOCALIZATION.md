## Штатная архитектура перевода

Frappe объединяет переводы приложений (CSV и скомпилированные PO/MO).
Установленное после LMS приложение `over_u` добавляет собственный `ru.csv`;
пользовательские записи DocType Translation имеют более высокий приоритет.
В существующие PO Framework/Learning и upstream исходники изменения не внесены.

* System Settings.language = `ru`; стандартное поле User.language остаётся источником предпочтения пользователя.
* Одноразовый patch `russian_default` устанавливает русский существующим включённым пользователям. `User.before_insert` ставит русский новым пользователям без явно выбранного языка. Последующие migrate не сбрасывают индивидуальный выбор английского.
* Guest: `before_request` выбирает русский по умолчанию, сохраняя явные `_lang`/preferred_language; это нужно, поскольку штатный Framework иначе предпочитает Accept-Language браузера.
* `/school`: сервер передаёт единый двуязычный словарь, `i18n.js` подставляет значения. Серверные сообщения используют `frappe._`; авторские данные остаются данными.
* LMS: стандартный `after_request` загружает **тот же** словарь Frappe до запуска Vue в standalone HTML. Это устраняет английские подписи при первом setup, поскольку штатный `__()` не реактивен, а загрузка словаря асинхронна. JSON экранирует `<`, запросы API/Desk/School этим hook не затрагиваются.
* Override `lms.lms.api.get_translations` возвращает штатный словарь по языку пользователя, с штатным fallback на язык школы. Не меняет авторизацию или данные обучения.
* Редакторы: поддерживаемые i18n конфигурации EditorJS/Plyr; копирование только отображаемых labels в menu descriptors RichTextEditor. Действия, IDs и доступность меню сохранены.
* Необёрнутые строки LMS/frappe-ui получают локализацию через проверяемый Vite build extension в OVER U. Только подписи, статусы, ARIA, даты и отображение диаграммы; значения API/форм/БД не меняются. Исходники зависимостей на диске не редактируются. При несовпадении ожидаемого исходника сборка останавливается и требует адаптации расширения.
* Desk: отдельный `app_include_js` локализует только известное декоративное приветствие setup wizard; состояние setup и конфигурация не обходятся.

Английские технические значения `Pass`, `Fail`, `Not Graded`, `Not Applicable`,
`Text`, DocType, методы, маршруты и роли сохранены. Они показываются переводом,
но не записываются в БД русскими значениями. Два известных системных примера POC
(описание зачёта в задании и правильный вариант вопроса) заменены точным patch,
с проверкой исходного текста. Автоматического перевода авторских материалов нет.

## Сборка и обновления

После установки приложения/обновления:

```sh
bench --site over-u.localhost migrate
bench build --app over_u
bench --site over-u.localhost clear-cache
```

Стандартный `after_build` запускает локализованную Vite-сборку LMS и сохраняет
обычные генерируемые assets. Нужны зависимости `frontend`, Node совместимой
версии и достаточная память; default heap extension — 6144 MB, если NODE_OPTIONS
не задан. Обычная LMS-сборка без финальной сборки OVER U может заменить эти assets.
Это нужно закрепить в CI/deployment после любого обновления upstream.

При зависании development-startup на сетевой проверке версии Bench помогает
штатная переменная окружения `FRAPPE_DOCKER_BUILD=1`. В текущей среде она задана
в отдельном runtime compose override вне Git; данные и тома сохранены.

При обновлениях сохраняются отдельные CSV/JSON/hook приложения OVER U. Проверяемые
build adapters — сознательный компромисс для upstream-компонентов без i18n:
они не требуют fork core, но должны пройти сборку и браузерные тесты на новой
версии frappe-ui/LMS. Безопасное долгосрочное улучшение — предложить upstream
обёртки перевода/поддерживаемые i18n props и затем удалить соответствующие adapters.

## Проверки

* 23 backend-теста OVER U: политика зачёта, student API, 6 новых тестов локализации.
* 41 upstream тест: 31 интеграционный + 7 unit по lesson locking, 3 по запрету самостоятельного зачёта задания.
* Полный Playwright-сценарий: новый временный ученик, тест 50% → блокировка,
  повтор 75% → продолжение, отправка → ожидание, прямой URL закрытого урока,
  штатный преподаватель → зачёт → разблокировка → 100%.
* Изоляция ответов и сохранение 100% существующего ученика; профиль/результаты,
  клавиатурная навигация, 320/390/768px, эквивалент 200% масштаба.
* Дополнительный сценарий: авторизация/ошибка, восстановление, кабинет
  преподавателя/список учеников, существующий/новый тест, новая работа,
  локализованные типы с неизменным внутренним `Text`, валидация, ошибка доступа.
* Отдельная проверка User.language=en для /school и /lms: английский UI возвращается, авторское русское название курса сохраняется; после проверки fixture возвращается на русский.
* Основные screenshot-сценарии проверяют английские слова и uncaught JS errors.
  Бренды, email, форматы файлов и клавиатурные сочетания исключены явно.
  В намеренно невалидной форме штатный resource дополнительно выдаёт browser
  rejection `/api/method/frappe.client.insert MandatoryError`; он записан в
  `expectedErrors`, пользователь видит русское сообщение обязательного поля.
  Остальные browser errors считаются отказом проверки.

Команды:

итоговое состояние без повторного прохождения. Реальные ученики не сбрасываются.

## Ограничения

До завершения setup wizard нельзя утверждать, что все администраторские формы
и все их динамические уведомления полностью русифицированы. Каталог Framework
имеет незаполненные записи; новые пользовательские DocType/поля требуют собственных
переводов. Следующий безопасный шаг для этого ограничения — согласованная настройка
тестового Desk и отдельный аудит форм пользователей/ролей/настроек через штатный
CSV приложения OVER U, без изменений core.

Названия OVER U/Frappe/YouTube, email, URL, форматы PDF и программные идентификаторы
не переводятся. Материалы автора остаются на языке автора. Подписи встроенного
HTML5-video и нативной валидации зависят от языка браузера/ОС, их нельзя гарантировать
через словарь приложения. Редкие сторонние всплывающие элементы вне проверенных
маршрутов не входят в обещание 100% всех интерфейсов.

Политика Teacher Pass, баллы, число попыток, прогресс, структура курса и дизайн
не менялись. Приватный backup, credentials и production-конфигурация не затрагивались.
